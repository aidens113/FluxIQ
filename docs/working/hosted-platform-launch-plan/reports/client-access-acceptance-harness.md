The host-proof resolver override is deliberately unused because it would bypass custody.

When run, the proof begins with keyless ordinary approval and an authenticated library request, then installs its synthetic model key through the normal privileged key-management operation. It measures model access after configuring the key later, ordinary approving-panel logout, reconnect without reapproval, Core restart before operator re-login, and password-free dialog reapproval. It preserves the copied-token/credential-reuse audit and trust-revocation checks. Finally, explicit Forget/reset must reach Core; the same request made with the now-revoked credential must return 401/403 without another stub call.
