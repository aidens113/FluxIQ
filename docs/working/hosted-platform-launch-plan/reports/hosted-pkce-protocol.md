# Hosted PKCE protocol proposal

Outcome: Done for read-only API/recovery proposal; implementation awaits root approval and extension-check release. Own only future `background/connect/pkce/**`; no existing source changed. Retain configured worker when follow-up model/effort override is unavailable.

Proposed factory: `createHostedPkceProtocol({ selection: { id, origin, clientLabel, extensionVersion }, isCurrent, credentials, attempts, authenticationTabs, tabs, fetch, crypto, now })`. Capture immutable selection; require a synchronous literal-true generation guard around every adoption-path await, permanently retiring the controller once it observes false. `authenticationTabs` is the existing `ready/own` port; `tabs` supplies only privileged `createBlank()` and `navigateOwned(tabId,url)` operations. Fetch and Web Crypto are injected, with no global network/storage/browser use in tests.

Methods: `start(): Promise<SafeAttemptView>`, `observe({tabId,url}): Promise<OwnerOutcome>`, `cancel(): Promise<SafeAttemptView>`, `restore(): Promise<SafeAttemptView>`. SafeAttemptView is strictly `{phase, attemptId?, failureCode?}`, using closed phase/fixed-code enums; unknown fields are refused. OwnerOutcome adds only optional adopted `{binding,installId,revision,lineageId,connectedClientId,userId,workspaceId}` for the owning background, never routed directly to UI. Neither contains credential/code/verifier/state/authorize URL/body/cause. Background can re-read the exact private record to construct the transport adapter.

Proposed injected session port:
```ts
type AttemptBase = { version: 1; attemptId: string; browserSessionId: string; selectionId: string; binding: HostedCredentialAudience; installId: string; expectedCredentialRevision: number; createdAtMs: number };
type StoredPkceAttempt = AttemptBase & ({ phase: "preparing"; tabId: null; state: string; verifier: string } | { phase: "waiting"; tabId: number; state: string; verifier: string } | { phase: "exchanging"; tabId: number; submittedAtMs: number } | { phase: "terminal"; tabId: number | null; outcome: "adopted" | "denied" | "cancelled" | "uncertain" | "failed"; failureCode?: SafeFailureCode });
type AttemptEnvelope = { browserSessionId: string; revision: number; attempt: StoredPkceAttempt | null };
interface HostedPkceAttemptStore {
  load(): Promise<AttemptEnvelope>;
  compareAndSwap(expected: { browserSessionId: string; revision: number }, next: StoredPkceAttempt | null): Promise<boolean>;
}
```
This private port must share AuthenticationTabs' authoritative browserSessionId and atomically match both session id/revision; unknown fields, malformed unions or a different session refuse. Only preparing/waiting carry state/verifier, never raw code. No local/sync or worker-memory substitute. Real backend requires separate explicit agreement: Chrome session storage lacks native CAS, so one background owner/serialized store must supply it; no active-active claim.
Start/restore fetch fresh discovery internally from immutable selected origin, parse actual contracts and construct checked binding; persisted audience is comparison data, never caller-forged discovery/plain-binding authority. Require service profile, instance id, PKCE=true, actual exported transport protocol, and explicit extension minimum satisfied by actual version. Missing/false/unsupported evidence refuses; no tokenless/typed-reference fallback. Read per-binding install id/revision. Recommend refusing existing active trust with trust_transition_required until caller performs explicit account/profile sequencing; no unlock ceremony.

Generate independent 32-byte state/verifier with injected crypto, base64url without padding, and Web Crypto S256; use the fixed client id and actual authorize/request schemas with URL/URLSearchParams. Persist preparing, create an inactive blank tab, await existing auth-tab ownership commit, persist waiting with tab id, then navigate. Never navigate if claiming fails. Keep owned tabs excluded after terminal states; protocol does not guess when closing/scrubbing/releasing a login/signup tab is safe.

Observe only the owned current tab at exact pinned origin and `/connect/done`, without URL credentials/query, with the strict existing fragment parser and exact saved state. Other navigation is ignored. A valid denial invalidates the attempt safely. Atomically CAS waiting to exchanging before POST, preserving request code/verifier only in that winning call's memory. Duplicate callbacks cannot both win; do not hold serialization across fetch, tab navigation, or other external waits so cancellation can progress.

POST once to pinned tokenUrl with fixed request schema, `fluxiq-client: browser-extension`, JSON content type, credentials omit, redirect error, cache no-store and referrer no-referrer. No cookie/password or forged Origin. Parse success/error through actual schemas and map only known codes to fixed outcomes, discarding descriptions/body/cause. Timeout, abort, lost response or 503 after submission is uncertain, never permission to retry the code. Validate real gateway equality, user/workspace summaries and server expiry before repository new-trust commit with captured revision and deterministic attempt operation id.

Cancellation first invalidates the controller generation and durable attempt, then aborts local I/O. A valid delivered response arriving after cancellation/switch must still journal its opaque proof against the original pinned binding; cleanup is allowed after selection becomes false and can never activate it. If own adoption commit already succeeded before cancellation was observed, conditionally Forget only that exact still-current revision/trust, atomically journaling cleanup. If newer state won, never clear it; journal only the unadopted original proof when safe. No automatic predecessor revocation during ordinary transport rotation.

| Recovery window | Policy |
| --- | --- |
| Same browser session, waiting | Rehydrate only after fresh discovery/binding/capability/selection and existing auth-tab ownership checks; no exchange merely because a restored URL contains a code. |
| Preparing without confirmed owned tab | Invalidate; never claim a guessed/restored tab id. A blank created before claim is not proof of auth ownership. |
| Exchanging or ambiguous response | Never repost on worker restart. Return interrupted/uncertain and require fresh consent; unknown issued proof cannot be claimed revoked. |
| Credential commit survived before attempt terminal write | No automatic callback replay/adoption. Stored trust remains independently available to its normal guarded private-read path; the interrupted attempt never resends exchange. |
| New browser session/missing or corrupt session state | Invalidate attempt and old tab ids; keep known auth/return/signup routes excluded. Existing registry intentionally discards old ownership and does not identify an unknown external restored auth page. Broader automation eligibility/recovery barrier and browser proof remain separate before enabling hosted composition. |

Acceptance after approval: fixed PKCE vector/independent entropy; exact compatibility/URL/body/headers; blank-claim-navigate order; duplicate/unknown/mixed fragments; wrong tab/origin/query/state; denial; one exchange winner; cancel/switch around each await; no replay after uncertain exchange/restart; malformed/expired/foreign-gateway success; durable adoption before usable result; known unadopted cleanup and failed cleanup status; secret-free views/errors. Use isolated injected session CAS/fetch/tab ports, actual schemas/private repository and fake IndexedDB, then the approved uniquely labelled filtered runner; no live sockets/server/provider or build.

Validation: read-only source trace of contracts, credentials and AuthenticationTabs; report diff check only. Not verified: protocol implementation, durable attempt backend, actual browser restart/tab recovery, network/CORS/permissions, PKCE end to end, or composed activation. Unknown external restored-auth privacy is a composition launch blocker. Root approved API direction but source remains held for the package checkpoint; no PKCE source file has been created.
