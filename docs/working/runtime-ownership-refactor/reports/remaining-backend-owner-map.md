## Dependency cuts and actual coupled groups

All-source relative import metadata has a 1,585-module component (1,246 runtime-declaration files), spanning the large Studio barrels and backend groups, plus a three-module flows/composites component. This includes type edges and is NOT a runtime/erased closure assertion. It argues for canonical contract-first cuts and narrow imports, not moving 1,585 files in one transaction or legitimizing reverse imports through old aliases.
Coupled state must move together: (1) pool/statement cache/close tracking and migration memo; (2) canonical-authority whole/project guard/ledger capability owners; (3) trial source/checkout/cache/mode/suppression companions; (4) conversation row/writer/settlement identity; (5) trace installation/episode/prefix ACK.
