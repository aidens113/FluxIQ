Status: Done; final source freeze reported to lead. Plain audit and the final named fixture/readiness checks pass; lead owns fresh compilers/browser and final eight-file acceptance.

## Actual causes

- The public `AutomationStudioService.generateFlowBootstrapAdaptation` evidence-guided path defines one `completion` callback, supplies it to the evidence loop, and also supplies it as `acceptStopped` to `runAutomationStudioFlowBootstrapBuildPhases` (`runtime/service.ts`, around 1603–1657). This is the executed owner, not an unused extracted helper.
- `llm/harness-options/bootstrap-completion.ts` `fromDraft` assembles the authoritative draft and consumes the assembler's trusted `draftStepIdByNodeKey` for inherited and amended parameters, but returns neither this mapping nor a draft-aware locator. Every refusal then calls `located(..., accepted.locator)` without a locator. An inserted optional-step join consumes an assembled node position; a `nodes.3.parameters` path therefore cannot safely identify draft step 4. Existing script/JSON reply locators do not fix this draft path.
- `flow-bootstrap/unfinished-build/phases.ts` sets the stopped-at-reserve/short-round test solely from the reserve, budget and replayable steps. `automationStudioFlowBootstrapJudgeUnfinished` then runs the whole trial. Only **after a clean replay**, `reserve-judging.ts` invokes the existing `acceptStopped` completion preflight. Thus a draft already known to have unresolvable parameters still runs whole when its call allowance ends.

## Implemented invariant and scope

Preserved refusal codes and paths. Draft feedback now carries `draftStep`, `draftStepId` and `nodeDefinition` from assembly's existing node-to-step mapping, including after optional joins and when authoring supplies a refused plan. Synthetic assembly lines are not shown as authored script lines. Generated joins and loops get no guessed source. Existing exact-definition checks in the mapping remain unchanged; no alias broadening or executable authority was added.

Moved the existing `acceptStopped` callback before fallback whole trials. A refused preflight runs neither trial nor judge; the known refusal code and incomplete draft survive. The accepted completion snapshot is reused for reserve judging, with only the trial's replay evidence added, without a second resolution against the page the trial left. Later rounds check the current draft afresh. Ordinary model-ready completion and stopped-short repair paths still pass. No call/cost/timeout limits changed.
