# @fluxiq/contracts

Browser-safe shared contracts for FluxIQ integrations.

```ts
import {
  CLIENT_GATEWAY_PROTOCOL_VERSION,
  type ClientGatewayClientMessage
} from "@fluxiq/contracts/client-gateway";
```

This package contains data contracts and runtime schemas only. It does not
include the FluxIQ Node runtime, SQLite, filesystem access, or UI components.
